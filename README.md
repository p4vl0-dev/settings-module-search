Небольшой модуль для [Foundry Virtual Tabletop](https://foundryvtt.com/), который расширяет поиск в окне **Game Settings**. Вместо поиска только по отдельным настройкам он позволяет быстро находить вкладки модулей по их видимым названиям в боковой навигации.

## Возможности

- **Поиск по названию вкладки.** Сопоставляется только видимый текст навигационной кнопки модуля. ID пакета, описание, авторы, подсказки и названия отдельных настроек не участвуют в поиске.
- **Динамическая фильтрация.** Список вкладок обновляется прямо во время ввода.
- **Стандартные категории остаются доступны.** Категории настроек Foundry и текущей игровой системы не скрываются результатами поиска.
- **Автоматическое открытие совпадения.** Если запросу соответствует ровно одна вкладка модуля, она открывается автоматически.
- **Сброс одним действием.** При очистке строки поиска все вкладки снова становятся видимыми.
- **Штатное поле ввода.** Поле поиска остаётся редактируемым: ввод, вставка, выделение и очистка работают как обычно.

Поиск применяется к вкладкам, уже присутствующим в окне настроек. Он не добавляет в навигацию отключённые модули или модули, у которых нет зарегистрированных настроек.

## Совместимость

Модуль рассчитан на **Foundry VTT v12 и новее**.

## Установка

### Через установщик Foundry

1. Откройте **Setup** → **Add-on Modules** → **Install Module**.
2. Вставьте ссылку на манифест:

   ```text
   https://github.com/p4vl0-dev/settings-module-search/releases/latest/download/module.json
   ```

3. Нажмите **Install**.
4. Войдите в мир и включите **Settings Module Search** в списке модулей.

### Вручную

1. Скачайте ZIP из [последнего релиза](https://github.com/p4vl0-dev/settings-module-search/releases/latest).
2. Распакуйте архив в `Data/modules/`.
3. Убедитесь, что итоговый путь выглядит так:

   ```text
   Data/modules/settings-module-search/module.json
   ```

4. Перезапустите Foundry или обновите список модулей на странице Setup.
5. Включите **Settings Module Search** в настройках нужного мира.

## Использование

1. Откройте **Game Settings**.
2. Начните вводить название нужного модуля в поле поиска.
3. В боковой навигации останутся стандартные категории Foundry и системы, а также вкладки модулей, названия которых соответствуют запросу.
4. Удалите текст из поля, чтобы вернуть полный список.

Регистр и диакритические знаки не учитываются. Если запрос состоит из нескольких слов, каждое слово должно присутствовать в названии вкладки; порядок слов значения не имеет.
